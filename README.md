## 0. The Unintentional Revelation

Memoria never intended to claim that "HTML is powerful."
However, through its implementation, it exposed a fundamental fact:

**Most complex social structures in the world can be established with just HTML + Time + Human Action.**

This is not a metaphor. It is an observable result demonstrated by running code.
Why is this possible? Because the core problem is not "computation," but "relationship."

* *Who did what, when?*
* *How did others react to it later?*

This is not advanced calculus; it is a history of events and references.
Memoria lays bare this minimal configuration. By stripping away servers and algorithms, we return the Web to its original, raw potential.

## 1. The Problem: Who owns the "Meaning"?

The Web was designed to be owned by no one.
But today, while we may own our "Data" (files), we do not own the "Meaning" (significance).

* **Current Web:** Centralized algorithms decide what matters based on immediate clicks and engagement.
* **Memoria:** **We separate "Existence" from "Meaning."**
    * *Existence:* Anyone can write anything. (Permissionless)
    * *Meaning:* Determined only by what continues to resonate over time. (Post-Hoc)

The question Memoria answers is not *"Who owns the data?"* but ***"Who decides what matters?"***

## 3. The Architecture

Memoria challenges the Web2 model of "Centralized Database + Algorithm."

1.  **HTML is the Player, JSON is the Record.**
    * The protocol logic is embedded in a static HTML file.
    * Data (logs) are simple, append-only JSON streams.
    * **Universal Replay:** As long as you have the ledger, the client can replay history and recalculate the state (Soul Mass) anywhere, offline, forever.

2.  **Fairness over Equality.**
    * Web2 treats 1 account as 1 vote (Equality), which is vulnerable to Sybil attacks.
    * Memoria uses **Wallet Mass (WM)** to weight resonance.
    * *Result:* A bot with 0 WM can shout, but its voice has 0 gravity.
